# Estudo Bíblico

App pessoal de estudo bíblico. HTML, CSS e JavaScript puros, sem etapa de build.

- Abrir no computador: `node tools/servidor.js` e acessar http://localhost:4190
- Publicação: cada push na `main` publica na Vercel.
- Anotações, grifos, sermões e progresso ficam no navegador de cada aparelho (localStorage). Para levar de um aparelho a outro: Caderno → Baixar cópia de segurança → Restaurar cópia.

## Créditos dos textos

- Bíblia Livre (CC BY 4.0) e Bíblia Portuguesa Mundial (domínio público), via eBible.org.
- Hebraico: Westminster Leningrad Codex. Grego: Textus Receptus.
- Interlinear e léxico: STEPBible Data (CC BY 4.0), Tyndale House, Cambridge.
- Referências cruzadas: OpenBible.info (CC BY).
- Glosas em português, verbetes, introduções, mapas, pessoas, dicionário, passagens difíceis e falas de Jesus: redigidos por IA, sem revisão humana.
